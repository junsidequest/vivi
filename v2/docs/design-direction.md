# Vivi v2：設計方向（2026-10-01 改版）

## 使用者偏好（沿用）

- 原始黑白版延伸，在 v2 獨立修改。
- 真人照片保留彩色，是全站唯一的色彩。
- 不使用裝飾箭頭；橫向內容以文字按鈕控制。
- chichinliu.com 僅作方向參考，不能相同。
- 以 Awwwards、Webby、FWA 的完成度為目標，使用 agent 交叉審查並迭代。

## 核心概念：翻譯

品牌主張是「把技術翻譯成人話，把想法做成日常」。整站用編輯排版（大字標、細線、章節編號）呈現，招牌時刻是第 01 段的捲動式翻譯舞台：技術術語一次一個放大顯示，捲動時被劃掉，再逐字浮現對應的白話說法。

## 視覺系統

- 色彩：紙白 `#f3f2ee`、次紙色 `#e8e6df`、墨黑 `#121212`，輔助灰 `#66655f` 與 `#76746c`（對淺底皆達 4.5:1）。
- 字體：Noto Sans TC（主文、900 字重大標）、Noto Serif TC（重點詞、金句）、Instrument Serif 斜體（英文點綴）、Inter Tight（編號、eyebrow、數字）。頁首與頁尾大字標沿用 Arial Black 的 vivi. 字樣。
- 節奏：淺色段與兩段全幅深色（工作情境、聯絡）交錯，中間以跑馬燈與金句過場打破固定結構。

## 資訊順序

首屏（主標、人像、四項數據）→ 跑馬燈 → 01 翻成人話 → 02 工作情境（深色）→ 03 關於 Vivi → 04 合作方式 → 金句過場 → 05 口碑推薦 → 06 服務流程 → 07 合作機構 → 08 聯絡與頁尾大字標。

## 動態原則

- 首屏逐行遮罩進場、手繪圈線描繪、人像輕微視差。
- 翻譯舞台與金句都由捲動進度驅動，不自動播放。
- 所有動態都尊重 `prefers-reduced-motion`：翻譯舞台改為靜態對照表，金句直接全顯示。
