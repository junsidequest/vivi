# Vivi 網站

- [主網站](https://junsidequest.github.io/vivi/)
- [探索小島](https://junsidequest.github.io/vivi/island/)

## 專案結構

| 路徑 | 用途 |
| --- | --- |
| `website/src/` | 主頁程式、樣式與內容資料 |
| `website/public/` | 主頁照片、媒體圖片、Logo 與認證素材 |
| `website/island-app/src/` | 小島程式 |
| `website/island-app/public/` | 小島模型、圖片與材質 |
| `.github/workflows/pages.yml` | GitHub Pages 自動建置與部署 |

開發與預覽方式請見 [website/README.md](website/README.md)。

部署先建置小島，再合併主頁建置結果。舊版頁面、舊小島、設計快照與預覽截圖不再納入目前版本；歷史版本仍可由 Git 紀錄查閱，本機另有備份。
