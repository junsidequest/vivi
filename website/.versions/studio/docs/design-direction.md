# Vivi 工作實驗室：目前設計方向

## 使用者偏好

- 原始黑白版延伸，在 v2 獨立修改。
- 真人照片保留彩色。
- 不使用裝飾箭頭；橫向內容以文字按鈕控制。
- chichinliu.com 僅作為更有設計感的方向參考，使用者明確要求不能相同。
- 以 Awwwards、Webby、FWA 的完成度為目標，使用 agent 交叉審查並迭代。

## 品牌與視覺

核心主題：「把技術翻譯成人話，把想法做成日常」。訪客為希望將 AI 用進工作的非技術工作者、企業團隊。

首屏以彩色 Vivi 人像、Vivi 簽名及淡色 v. 字樣建立辨識；主標將 AI 的英文襯線與「工作」兩字的中文襯線融入原本的中文無襯線字體。移除手繪圈、Human first、直排字及傾斜名片。

顏色以紙白、墨黑、低飽和中性灰為主，材質靠低對比光感與細線呈現。工作情境是唯一完整深色段落，聯絡區改成留白收尾。所有裝飾都不得阻礙閱讀或成為額外操作門檻。

## 資訊順序

首屏 → 經驗摘要 → 合作方式與公開課程 → 工作情境示範 → 自介與認證 → 推薦與媒體 → 服務流程 → 內訓合作機構 → 諮詢。

企業／個人服務直接連現有諮詢表單；公開課程使用持續可見的線上／實體分頁，明確區分既有開課紀錄與最新招生資訊。
