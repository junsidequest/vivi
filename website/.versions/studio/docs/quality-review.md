# 目前版本自檢紀錄

日期：2026-10-01

## Agent 交叉審查

1. UX agent：檢查服務決策、CTA、課程可發現性與可讀性；實作獨立 Services 元件。
2. 視覺 agent：檢查主視覺元素密度、黑白段落節奏、字級及響應式衝突；再審查整合後的樣式。
3. 主 agent：整合、修改視覺與資訊順序，並在瀏覽器實測。

## 本輪修正

- 保留彩色人像及無箭頭方向；縮減首屏裝飾，改用字體、材質與人物構圖建立識別。
- 工作情境改為完整深色面板，保留點選及鍵盤切換。
- 服務移至自介之前，兩種合作均有適用對象、內容及直接表單入口。
- 公開課程取消翻面，改為持續可見的線上／實體分頁，保留原有課程網址。
- 統一主要章節的字級與字重，手機與平板主要斷點統一在 700px。
- 主要內容略過連結直接對應 main；載入動畫不隱藏首屏內容。

## 已實測

- 320、390、601、701、768、1440px 頁面寬度檢查；包含 700px 附近的平板切換。
- 頁框及導覽未出現橫向溢出；抽查圖片無載入失敗。
- 701px 人像與主標 bounding box 無相互遮擋。
- Noto Serif TC「工作」字體載入檢查通過。
- 工作情境可點選切換；公開課程可點選及以 Home 鍵返回線上分頁。
- 瀏覽器抽查未記錄 error 或 warning。
- 正式建置通過。
