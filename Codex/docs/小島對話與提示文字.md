範圍：`Codex` 網站目前程式中的文字與導向，未更動網站文案。網址以 `http://localhost:8795/` 為基準；部署後以正式網址替換主機即可。

## 佈告欄

- 標題：把 AI，帶進你的日常。
- 內文：嗨，我是陳盈臻 Vivi，也有人叫我大師姐。我不是工程師，卻把 AI 真的用進了工作裡。現在，我陪非技術背景的團隊跨出第一步。
- 靠近提示：按 E 看佈告欄（手機為按 A 看佈告欄）
- 自動前往提示：正在前往認識 Vivi…
- 按鈕：多認識我一點 ↗ → `?view=professional#about`，播放收合轉場後進入黑白版的關於我區塊。

- 按鈕：看看課程與服務 ↗ → `?view=professional#offers`，播放收合轉場後進入黑白版的課程與服務區塊。

## 信箱

## 操作說明（小 i）

- 標題：操作說明
- 點擊地面移動，或使用鍵盤
- 鍵盤示意：W、A、S、D／上、下、左、右方向鍵，中間文字「或」
- 跑步：Shift
- 與附近物品互動：E
- 左側選單可快速前往。手機可點地面或拖動搖桿，按 A 互動。
- 繼續逛逛 →：關閉操作說明，繼續探索。
- ×：關閉對話（無障礙名稱）。

進入小島載入完成後自動開啟一次；小 i 可以再次開啟。下載模型按鈕已移除。

## 選單及其他控制

| 文字／圖示 | 行為或去向 |
|---|---|
| Vivi 的小島 | 選單標題，無連結 |
| 佈告欄 | 自動走到佈告欄，轉身面向它，再開對話 |
| 信箱 | 自動走到信箱，轉身面向它，再開對話 |
| 課程與服務 | 收幕轉場後前往 `?view=professional` 最頂端 |
| i／操作說明 | 開啟操作說明 |
| ▶ | 選單目前選取項目，裝飾提示 |
| 展開選單／收合選單 | 手機漢堡選單的無障礙名稱 |
| A | 手機互動按鈕，與附近物件互動 |
| 移動搖桿 | 手機搖桿無障礙名稱，控制行走 |

佈告欄 pin、信封圖示本身沒有文字；靠近時改顯示操作文字。滑鼠移到佈告欄、信箱、小鴨時顯示整體外輪廓，沒有另外增加 hover 文案。

## 提示時序

- 開場台詞：可顯示時延遲至少 1.3 秒，顯示 6.5 秒；操作說明開啟時不開始。
- 走動時的遠處物件提示：顯示 3.5 秒、隱藏 9 秒；停走 2.5 秒後休眠。
- 靠近物件 2.1 單位內：顯示較近物件的圖示；佈告欄與信箱互動文字的觸發距離同為 1.15 單位。
- 點擊提示／選單後，該提示暫時收起，走開後恢復。
- 閒置約 30 秒：輪流顯示閒置台詞 4 秒。
- 小鴨互動台詞：顯示 3.5 秒，離開互動範圍會提早收起。
