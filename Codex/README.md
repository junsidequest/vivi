# Vivi 的 3D 小島

獨立建立在 Codex 目錄，原本的 island 網站不受影響。

## 啟動

在此目錄執行：

```sh
npm ci
npm run dev
```

開啟 http://localhost:8795/ 。也可在 macOS 雙擊 `start.command`。

## 入口與兩種瀏覽模式

- `/`：雙人物卡片入口；滑鼠懸停或鍵盤焦點切換卡片與背景。
- `/?view=island`：原本的 3D 小島，選擇後才載入場景。
- `/?view=professional`：黑白簡約的講師介紹頁，使用指定的真實照片。
- 小島的佈告欄與小屋對話按鈕經轉場前往黑白介紹頁；黑白頁上方可前往小島。此版本不包含舊像素介紹頁。

入口元件為 `src/Welcome.jsx`、樣式為 `src/welcome.css`。黑白頁為 `src/Professional.jsx` 與 `src/professional.css`，介紹內容保存在 `src/content/professional.html`。照片為 `public/img/vivichen.png`。

## 操作

- WASD 或方向鍵移動，Shift 跑步，E 與附近物件互動。
- 點擊空地、步道或碼頭即可指定落點，會自動避開障礙物；新點擊可改變目的地，鍵盤可隨時接手。
- 點擊地標或上方選單，自動繞路前往並開啟互動。
- 鏡頭固定角度與比例，平移跟隨角色；沒有縮放、旋轉操作。
- 觸控裝置使用搖桿。進入小島會顯示操作說明。

## 模型與碰撞

`public/3d/vivi-island.glb` 是真正的立體場景，可在 Blender 使用 File → Import → glTF 2.0 匯入。角色以原本的 `public/3d/vivi.glb` 為基礎，保留鈕扣細節、移除髮夾並統一頭髮材質，匯出為 `public/3d/vivi-detailed.glb`，保留貼圖、骨架與步行動畫。網站與 Blender 使用同一份島嶼幾何資料。

木棧道與階梯以網格頂面判斷踩踏高度，逐幀取樣角色雙腳頂點調整高度。這是腳底貼地與整體高度修正，尚非雙腿獨立 IK。全身阻擋依實際動畫頂點分高度建立輪廓，另保留約 2 公分的接觸容差。這仍是分段的保守近似，不是每幀逐三角形的角色碰撞。地面支撐取自模型表面，沒有預設島嶼邊界或房屋矩形封鎖區。移動採細分步進防止跑步穿過薄物件，尋路沿用相同碰撞判斷。

碰撞資料在載入時從模型建立。Island_ground 的 grass 材質、Stone_path、Dock、Steps、Path_base 為支撐表面；其餘可見網格皆為障礙，不需要手動畫阻擋區。新增或移動動態物件後需要重新建立碰撞資料。

## 開發與驗證

```sh
npm test
npm run model:export
npm run avatar:export
npm run build
```

模型來源為 `src/world3d/buildIsland.js`，經 `scripts/cc0-island.mjs` 組裝緊密木棧道；更改後重新匯出 GLB。測試包含全身阻擋、快速移動、尋路、表面高度，以及真實角色不同步態／方向／木板邊緣的腳底頂點檢查。

場景重建採用陶土圓瓦、蜂蜜色木作、奶油石牆與深綠樹冠。木紋貼圖已嵌入 GLB。角色外觀保留，步速、加減速、轉身及待機呼吸分別調整。

畫面比例與庭院氛圍參考 https://worawork.vercel.app/ ，場景幾何於此專案建立。黑白版介紹內容收於 `src/content/professional.html`。

庭院包含候課盪鞦韆與書刊箱、池邊長椅與澆水壺、圓角狗屋、入口立柱及長方形圓角綠籬。中央直向木棧道維持原位，左支線下移至狗屋後方，通往鞦韆前方，右支線沿池邊轉向長椅前方；信箱及鞦韆前方圍欄、箭頭牌已移除。玻璃位於窗框前方且與牆面分離，新增設施沿用網格碰撞。

門前平台加深，允許角色由上層階梯向左右跨下；保留實際模型碰撞與下階緩降。

鍵盤及搖桿遇到邊角時會嘗試小角度繞行，每次偏移仍檢查完整通行路徑。

朝長椅或盪鞦韆前方走近會自動坐下，也可直接點擊座位走過去坐。放開方向鍵後再移動，或點選地面，即可起身繼續散步。坐姿沿用 Vivi 原本骨架，座位位置與朝向記錄於 GLB 模型。

狗屋位於左側休憩區，書刊箱位於鞦韆左側。

右側木棧道沿長椅前方往下延伸，繞過信箱下方回接中央步道，形成環狀動線。

鞦韆朝向右下角，坐姿以實際角色頂點保留椅背間距。坐穩後，座椅、吊繩與角色繞上樑吊點同步擺動；起身前先停穩。
